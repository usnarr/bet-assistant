# F13 evidence: walk-forward harness on synthetic data (MOD-01, F10.7, F08.8)

Status: engineering tests pass. All data is synthetic and fictional, so none of these
results is evidence that a model works on real matches. Release classification:
`INCONCLUSIVE`. No source is approved and there is no execution-grade replay.

Command: `uv run pytest tests/test_backtesting.py -q`.

## Synthetic study

`tests/backtest_support.py`, seed 11, 150 matches, 12 players:

- Setup:
  - One match every 12 hours from 2026-01-05.
  - Cutoffs at 24 hours and 1 hour before the start.
  - Ranking, Elo and serve counts come from the players' true serve and return strengths.
- Split (300 snapshots, 288 in the split, 12 excluded after the last fold):
  - Warm-up: rows before the first fold are used for training only.
  - Three expanding folds of 12 days from 2026-02-09, with 48 test rows each.
- Candidates:
  - `baseline-ranking` and `baseline-surface-elo`, each with 20 bootstrap draws.
  - `point-serve-return`, with 10 draws and format `bo3-tb7-v1`.

| Model | Rows | Log loss | Brier | Cal. intercept | Cal. slope | Accuracy | AUC |
|---|---:|---:|---:|---:|---:|---:|---:|
| baseline-ranking | 144 | 0.468489 | 0.151038 | -0.378990 | 2.089128 | 0.819444 | 0.883450 |
| baseline-surface-elo | 144 | 0.535904 | 0.171139 | -0.234504 | 0.929939 | 0.763889 | 0.820804 |
| point-serve-return | 144 | 0.485733 | 0.157437 | -0.496601 | 1.260945 | 0.763889 | 0.871795 |

In this fixture, ranking beats Elo because the synthetic rankings come directly from the
true strengths. This is a property of the fixture, not a finding about real tennis.

## F10.7: point model versus surface Elo on matched rows

- Paired difference `point - surface Elo`: mean log loss -0.050172.
- The 90% week-block interval is [-0.091163, -0.006514], with 6 weeks, 200 draws and
  seed 20261001.
- Test settings (`full_config` in the test file) give these gate results:

| Gate | Result |
|---|---|
| sample, beats surface Elo, stable folds (2 of 3), single-week check, reproducibility, rollback, leakage flag | PASS |
| severe calibration: fold 1 intercept -1.203822 breaches the 0.5 test limit | FAIL |
| consensus calibration, economics, reviewer | BLOCKED |

Decision: `FAIL`. The point model stays `EXPERIMENTAL`. A held-out comparison on approved
real data is still required.

## F08.8: environment ablation, negative control

- Setup: `core-v1` against `core-env-v1`, with the surface Elo baseline on 80 matched
  cutoffs.
- Result: the log-loss difference is exactly zero, as expected. Surface Elo reads no
  environment feature, and no weather source is permitted.
- Limit: this proves only that the ablation path matches rows and does not change results
  when features are unused. A real ablation needs a multi-feature candidate (F11) and a
  permitted weather source.

## Other checks

- **Splits:** each match stays in one fold across both cutoffs, including matches that
  cross a boundary. A row moved to another fold is rejected, and so is a training row from
  the tested fold or with a later label.
- **Runner:** a rerun gives the same content hash. Fits with no serve counts are
  `BLOCKED`, and their rows are `fit_blocked`. Unverified formats abstain, and coverage
  falls.
- **Metrics:**
  - Hand-checked: log loss 0.366985, Brier 0.1, AUC 1, and a tie gives AUC 0.5.
  - Sparse segments are `INCONCLUSIVE`.
- **Bootstrap:** the same seed gives the same interval, and another seed gives a different
  one. One block gives no interval. A zero denominator is rejected.
- **Economics (hand example):**
  - Profit -15.00, ROI -0.3, drawdown 30.00 (0.260870), and a losing streak of 3 across a
    void.
  - CLV is observed for 1 bet and missing for 4.
- **Promotion:**
  - The draft repository configuration gives `BLOCKED`.
  - A self-review, a configuration frozen after evaluation, a failed leakage suite or a
    different rerun hash each give `FAIL`.
- **Bundle:** file hashes match the manifest. A second write to the same run is refused,
  and the bundle contains no local path.
